# Titanic - Machine Learning from Disaster

## Project Overview

This project focuses on predicting passenger survival on the Titanic using machine learning techniques.

It is based on the Kaggle competition **Titanic - Machine Learning from Disaster**.

The objective is to build a classification model that predicts whether a passenger survived based on passenger information such as age, sex, passenger class, family size, and other features.

## Dataset

The dataset contains information about Titanic passengers.

- Training set: 891 passengers
- Test set: 418 passengers
- Target variable: `Survived` (0 = Not Survived, 1 = Survived)

The dataset is available on the Kaggle competition page.

## Project Workflow

1. Data Loading and Exploration
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. Data Preprocessing
5. Model Training and Evaluation
6. Model Comparison
7. Hyperparameter Optimization
8. Nested Cross-Validation
9. Threshold Analysis
10. Model Interpretability using SHAP
11. Final Predictions and Kaggle Submission

## Machine Learning Models

The following models were implemented and evaluated:

- Logistic Regression
- Random Forest
- XGBoost

XGBoost was selected for further optimization based on its cross-validation performance.
